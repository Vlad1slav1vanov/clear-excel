# Security policy

## Supported versions

Security fixes are made for the latest major release.

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a vulnerability

Please use GitHub's private
[security advisory form](https://github.com/Vlad1slav1vanov/clear-excel/security/advisories/new).
Do not open a public issue for a suspected vulnerability.

Include the affected version and workbook format, the impact, reproduction
steps, and any suggested remediation. Do not submit confidential workbooks or
files containing personal data; use a minimal generated sample where possible.

Reports are reviewed on a best-effort basis. A validated issue will be handled
privately until a fix and coordinated disclosure are ready.
